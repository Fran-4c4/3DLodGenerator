# First surface controls

Original synthetic data under [MIT](../../LICENSE), not a real survey or a
certified vertical datum. Four independent objects: Road with a 10% longitudinal
grade, Terrain with a 29 m peak, Forest with ground/canopy returns, and Water
at 24 m. Width and shape come from polygons. This is not a stitched minimum scene.

`footprints.gpkg` contains canonical `surfaces` plus the existing building
regression layers. `surfaces.las`/`surfaces.json` drive this stage and
`surface-truth.json` contains independent controls. Building configurations are
separate integration controls, not merged into this command's result.

From the repository root, use a new output directory:

```powershell
.\.venv\Scripts\python.exe -m lodext build-surfaces examples/surfaces_first_run/surfaces.json --output outputs/surfaces-first-run
```

The included `model.surfaces.city.json` was generated by the public workflow.
See [the complete guide](../../docs/surface_workflow.md). Regenerate inputs with
`lodext demo-surfaces --output <new-directory>` without modifying this example.
