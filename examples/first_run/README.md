# Synthetic first-run dataset

Original 3DLodExt data under [MIT](../../LICENSE), not a real survey or certified
geodetic reference.

Four Building parents and five parts: courtyard (6 m), terrace (1.8 m), concave
body (8 m), disconnected body (5 m) and sparse body (4 m, two roof points).
The DTM is constant 25 m. The cloud has class-2 ground and class-6 roof points,
with an approximately 5 points/m² synthetic grid on well-supported bodies.
This is not a density/accuracy claim about a real survey.

`build.json` enables explicit external fallback for the sparse body.
`build.known.json` uses supplied heights; `build.lod0.json` generates only
surfaces. `truth.json` stores independent synthetic dimensions. Modal estimates
may differ by up to half a bin; parameters are not tuned to force equality.

Included `model.lod*.city.json` files were generated by the public workflow and
can be opened before running the program. Follow the [tutorial](../../docs/first_run.md)
to reproduce them, placing new outputs outside this versioned example.
